# ShopLocal

ShopLocal is a simple e-commerce web application designed to connect customers with local businesses and products. The platform allows users to browse products, view product details, manage shopping carts, place orders, and maintain user profiles through an intuitive interface.

## Features

### Customer Features
- Browse available products
- View detailed product information
- Add products to cart
- Checkout and place orders
- User authentication
- Manage user profile
- View order history
- Contact support

### Pages Included

| Page | Description |
|--------|-------------|
| Home | Landing page and featured products |
| Products | Product catalog |
| Product Detail | Detailed product information |
| Cart | Shopping cart management |
| Checkout | Order processing |
| Orders | Order history |
| Login | User authentication |
| Profile | User account management |
| About | Information about ShopLocal |
| Contact | Customer support and inquiries |
| Wishlist | Saved products |

## Getting Started

### Prerequisites

You only need a modern web browser such as:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

### Installation

1. Clone the repository:

```bash
git clone https://github.com/0xMawu/shoplocal.git
```

2. Navigate to the project directory:

```bash
cd shoplocal
```

3. Open `index.html` in your browser.

Alternatively, use a local development server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
